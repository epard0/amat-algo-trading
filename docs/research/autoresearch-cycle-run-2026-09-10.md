`cached` comparisons. No provider calls were made and no strategy/configuration
was changed. This validates idempotent scheduling and report reuse, not new
research discovery. The registry now contains four cycle events, ten completed

## Interpretation

- v9 underperformed v6 by 11.20 percentage points of total return, with lower
  Sharpe and a deeper drawdown despite more fills.
- v10 underperformed v6 by 41.43 percentage points, with substantially more
  fills and lower Sharpe. This is a strong negative result for that configuration
  under the imported cost/model assumptions.
- Matched v11 increased total return by 4.99 percentage points versus v10, but
  Sharpe declined 0.0307 and maximum drawdown worsened by 1.80 percentage points.
  The result is not a clean risk-adjusted improvement.
- v12 cannot be compared to v6 from these artifacts because sample dates/counts
  differ. Its apparent return gap is intentionally suppressed in model reports.

The current evidence therefore does not justify automatic strategy promotion.
The most valuable next loop is a fresh, clean-revision matched control/candidate
run with daily return series, trade ledger/accounting parity, cost stress, and
single-variable ablations. The chief’s backlog should propose those experiments;
an operator-approved allowlisted worker must execute them. Model output is not an
execution command, and this cycle did not touch the executor.
